# Partnership System

This directory is the home of Archy and Nessy's living bridge partnership
system.

The unchanged source RTF documents and their fingerprints live under
[`legacy/`](legacy/README.md). Semantic Markdown notes belong under
`agreements/`; provisional conversion or review material may use `migration/`
without turning an initial method into permanent policy.

The source documents have no automatic precedence. Record disagreements in
[migration/pending-updates/conflicts.md](migration/pending-updates/conflicts.md)
instead of silently choosing one wording. See [migration/README.md](migration/README.md)
for the current exploratory tooling.

The partnership's written agreements are authoritative. Read
[AGENTS.md](../AGENTS.md) for the preservation rules and
[habitable-scaffolding.md](../field/habitable-scaffolding.md) for the
collaboration field.
