# Partnership System

This directory is the future home of Archy and Nessy's living bridge
partnership system.

The source RTF documents have not been imported yet. When they arrive, their
unchanged originals belong under `legacy/`; semantic Markdown notes belong
under `agreements/`; and provisional conversion or review material may use
`migration/` without turning an initial method into permanent policy.

The partnership's written agreements are authoritative. Read
[AGENTS.md](../AGENTS.md) for the preservation rules and
[habitable-scaffolding.md](../field/habitable-scaffolding.md) for the
collaboration field.
