# Partnership Agreements

This directory holds human-reviewed Markdown representations of Archy and
Nessy's written partnership system. The legacy RTF sources remain authoritative
source evidence; these notes are the maintainable working form.

## Note Shape

A note may cover one substantial semantic topic and use subsections for its
internal agreements. File count is not a target. Split a note when a part:

- changes independently often enough to deserve its own history;
- needs to be linked as a distinct agreement;
- belongs to a different semantic area; or
- has become unwieldy to review and maintain as a subsection.

Do not split merely because the RTF uses another heading. Do not merge across a
real disagreement; record the disagreement in
[`../migration/pending-updates/conflicts.md`](../migration/pending-updates/conflicts.md).
