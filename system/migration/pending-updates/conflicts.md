# Source Conflict Tickets

The legacy documents have no automatic precedence over one another. When two
passages disagree, preserve both readings and open a ticket here for Archy and
Nessy. Do not silently select, merge, modernize, or reconcile them.

## Ticket Template

```markdown
### CONFLICT-NNN — Short title

- Status: open
- Affected note: `path/to/note.md` or `not created yet`
- Source A: `document.rtf > heading path`, rendered page or source byte offset
- Source B: `document.rtf > heading path`, rendered page or source byte offset
- Difference: factual description without proposed correction
- Downstream agreements: known affected notes, or `unknown`
- Resolution: pending Archy and Nessy
```
