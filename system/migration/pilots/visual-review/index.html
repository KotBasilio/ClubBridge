How to read the diagrams

  • The orange pane is the current RTF parser's row/token interpretation. It does not claim rowspan or colspan knowledge.
  • The blue pane is clean geometry from Word-exported HTML. It uses real rowspan and colspan attributes, without Word CSS.
  • Matching T-numbers identify the same ordered non-empty wording.
  • Within-cell whitespace and line breaks are normalized exactly as in the matcher; wording, punctuation, and suit symbols are retained.
  • These HTML files contain inline CSS only: no scripts, external resources, or network-dependent links.
Limitation: the right pane renders the Word-exported HTML geometry. It is not an independent rendering of the original Word/RTF document. The left pane is the current parser's flattened interpretation, not reconstructed merge geometry.
